Rubric / Feature Explanation

  • Draw a Cube: Implemented using Cube class and drawTriangle3D.
  • Matrix: Used Matrix4 for all transformations.
  • Render Function: All drawing logic is inside renderScene().
  • 8+ Parts: Sloth has 29 parts (Head, Body, Limbs, Claws, Tail).
  • Joints: Shoulder and Elbow sliders control hierarchy.
  • Animation: Walk cycle (on/off button) with phase offsets for natural movement. It also has a subtle breathing animation with the head bobbing up and down.
  • Non-Cube Primitive: Created a Cone class used for Claws and Tail Tip.
  • Poke Animation: Shift+Click triggers a special Barrel Roll flip.
  • Mouse Control: Click and Drag rotates the camera (X and Y axis).
