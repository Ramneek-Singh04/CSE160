Assignment 4: Lighting

Lighting has been fully implemented, including ambient, diffuse, and specular components. The UI on the right controls all features. The point light and spotlight can be toggled on or off as needed. A color picker is also included for the point light to test different lighting conditions.

For the 3D model requirement, the bunny.obj file was utilized. The assignment documentation indicates it has only 2,503 vertices and 4,968 faces. This was selected to avoid the performance lag that can occur with high-vertex models. The model was scaled up and colored chocolate brown. Additionally, a 3-block-high wall was added around the perimeter to integrate the world environment from the previous project.

Regarding AI usage, an AI assistant was utilized as a debugging tool during development. It was used to review scripts for typos and to explain normal matrix math when lighting appeared warped on rotated objects. It also provided clarification on spotlight vector math. The actual logic was constructed independently, but the tool streamlined the troubleshooting process.

The project runs directly from the HTML file. Normal visualization also functions correctly when toggled.
